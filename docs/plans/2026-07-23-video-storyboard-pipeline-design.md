# 长视频反推与内容生产流水线设计

## 目标

将一条长视频通过可配置的视频理解模型反推出结构化分镜、文案、台词、标题和话题，并在 Infinite Canvas 中生成可编辑的文本、音频和视频配置节点，支持逐镜头重新生成。

## 范围

首版包含：

- 整段视频上传到用户配置的视频理解模型脚本。
- 输出视频概要、原始文案、镜头时间码、画面、运镜、动作、台词、旁白、字幕、音效、转场和生成提示词。
- 按镜头创建“分镜文本节点 + 视频生成配置节点”。
- 创建可编辑的改写文案、标题/话题和音频配置节点。
- 修改单个镜头文本或参数后，独立重新生成该镜头。
- 复用现有视频模型的 2-15 秒时长、比例、分辨率、声音和水印参数。

暂不包含：

- 本地 FFmpeg 拆镜头、抽帧或语音转写。
- 自动剪辑合成最终长视频。
- 一键发布到第三方平台。
- 将原始长视频直接作为生成参考视频。

## 方案

采用浏览器直连的模型脚本方案。前端读取视频节点的本地 Blob/File，将视频交给用户配置的“视频理解”脚本；脚本负责上传、轮询和返回 JSON。前端只负责校验结果、规范化结构并写入画布。这样保持项目现有的浏览器直连和用户本地配置模型方式，同时不绑定单一供应商。

推荐的分析结果结构：

```ts
type ReverseVideoResult = {
    summary: string;
    style?: string;
    originalCopy?: string;
    titles?: string[];
    hashtags?: string[];
    shots: Array<{
        startMs: number;
        endMs: number;
        visual: string;
        camera?: string;
        action?: string;
        dialogue?: string;
        narration?: string;
        subtitle?: string;
        soundEffect?: string;
        transition?: string;
        generationPrompt: string;
        videoParams?: Record<string, unknown>;
    }>;
};
```

## 画布数据流

```text
原始视频
  -> 视频反推分析
  -> 整体文案 / 改写文案 / 标题话题
  -> 分镜文本 01 -> 视频配置 01
  -> 分镜文本 02 -> 视频配置 02
  -> 分镜文本 N  -> 视频配置 N
  -> 台词/旁白 -> 音频配置
```

每个分镜配置使用独立的生成提示词和参数。由于视频生成接口限制单个参考视频 2-15 秒、总参考时长不超过 15 秒，首版只使用反推结果生成提示词，不把整条长视频作为参考输入。

## 交互

- 在视频节点工具栏增加“反推分镜”。
- 弹窗展示分析模型、分析脚本、改写要求和输出语言等参数。
- 分析中显示进度，失败时保留原始模型响应并允许重试。
- 分析成功后按镜头顺序排列节点，并选中第一个视频配置节点。
- 文本节点和配置节点均可独立编辑、重新生成和删除。
- 节点创建保持当前主题、扁平工具栏和原始媒体比例规范。

## 错误处理

- 视频文件过大、格式不支持或模型拒绝上传时显示明确错误。
- 模型返回非 JSON 或字段缺失时，尝试提取 JSON；仍失败则保留原始响应并提示修正脚本。
- 单个镜头字段缺失时使用空值和默认参数，不阻塞其他镜头创建。
- 镜头时间码重叠、倒序或超出视频时长时进行规范化并标记警告。
- 生成节点不自动绑定长视频，避免触发参考视频时长限制。

## 后续阶段

- 对分析结果按转场和动作自动拆分并生成可预览片段。
- 新增时间线/自动剪辑节点，按镜头顺序合成视频和音频。
- 增加导出和平台发布适配器；发布前单独处理账号授权和平台权限。
